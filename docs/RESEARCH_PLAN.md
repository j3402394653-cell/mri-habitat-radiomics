# 研究范围与阶段安排

## 项目目标

探索多序列MRI生境表征的预测价值，当前聚焦直肠癌脉管侵犯。已有课程报告作为一项阶段性技术总结，仓库继续用于积累源码、实验与分析。

## 已完成的当前阶段

- 整理2026年10月25日直接PLS四组实验源码及相关依赖。
- 保留120例队列的训练、外层五折与内部测试汇总结果。
- 提供不依赖患者数据的汇总指标和源码哈希核查工具。

104个模块包含历史import依赖，不代表所有旧实验都列为当前主结论。当前结果以configs与results中的阶段配置为准。

## 后续研究方向

以下是待实施的研究安排，不是已经取得的实验结果。

1. 进一步核对影像时点、脉管侵犯结局和IVIM参数的量值与质量。
2. 分析患者内生境分区、轮廓扰动与特征选择的稳定性。
3. 在同一患者划分与训练预算下设置匹配的纯临床对照，检验生境信息的增量价值。
4. 完善纯生境表征，比较区域统计、区域对比与各序列贡献。
5. 固定较简洁的联合模型，使用未参与开发的新患者开展验证。

## 实验记录方式

每项新研究单独记录研究问题、假设、队列与划分、输入、比较组、选择规则、运行版本、汇总结果及分析。新旧数据划分分别命名，结果不覆盖。修改建模流程后，应把新的模型结果与对应配置一并保存。

后续扩展其他预测结局时，应单独定义标签、样本与评价流程，不将脉管侵犯实验结果沿用为其它任务的验证证据。
