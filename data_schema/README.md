# 私有数据接口说明

本目录仅解释输入结构，不包含患者记录、影像、标签、特征矩阵或患者编号。

- 影像输入：每位患者各自物理空间中的 T2、ADC、IVIM D/f 及对应 ROI；不能把不同序列强行当作逐体素对齐。
- 结局输入：既有临床资料中的脉管侵犯二元字段，1 为阳性，0 为阴性。
- 术前临床变量：术前 T、N 分期，EMVI，MRF，logCEA，年龄，性别，MRI 位置、厚度、长度、环周占比。
- 内部特征对象：indices、metadata、base、erode、dilate；三种轮廓下列定义保持一致，metadata 给出特征名称和模态。
- 原工程还使用病例映射、既有划分清单、影像质量缓存以及实验冻结记录。公开包未包含这些材料。

获得医院或数据持有方授权后，才能在受控环境准备这些输入。公共仓库不能单独完成原始患者级训练复现。公开结果复核入口见根目录 README。
