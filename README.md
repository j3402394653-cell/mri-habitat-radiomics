# MRI生境影像组学探索

本项目围绕多序列MRI中的肿瘤内部异质性，研究生境分区、区域特征表达、特征稳定性与临床信息融合。当前以直肠癌脉管侵犯预测为主要任务，持续记录方法实现、对照实验和阶段性发现。

## 研究问题

- 如何在T2、ADC和IVIM D/f中构建并描述肿瘤生境？
- 轮廓变化、标准化方式和特征筛选如何影响预测表现？
- 生境特征与术前临床信息融合能带来怎样的增益？

## 当前实现

现有流程包括1 mm重采样、患者内K-means生境分区、区域影像组学与空间特征提取、轮廓扰动分析、训练部分内特征筛选、PLS降维和正则化逻辑回归。T2与ADC采用各自ROI，IVIM联合D/f构建生境；各序列在患者特征层合并。

当前公开版本对应2026年10月25日已完成的直接PLS四组对照，比较方向筛选有无及临床信息有无。源码快照保留主入口及相关历史依赖，便于查看实际实现和追溯研究过程。

## 阶段实验

数据来源为福州大学附属省立医院。本阶段从138例既有资料中进行一次分层抽样，形成120例队列，其中84例训练（57阳性、27阴性），36例内部测试（25阳性、11阴性）。训练部分采用外层五折、内层五折重复三次的嵌套验证。

| 模型 | 训练拟合AUC | 外层五折均值 | 内部测试AUC |
|---|---:|---:|---:|
| 无方向筛选 纯生境 | 0.8317 | 0.6027 | 0.7855 |
| 无方向筛选 生境加临床 | 0.8596 | 0.7573 | 0.8073 |
| 固定85%筛选 纯生境 | 0.7589 | 0.6018 | 0.6945 |
| 固定85%筛选 生境加临床 | 0.8538 | 0.7752 | 0.7927 |

临床融合提高了两组流程的交叉验证表现，85%方向筛选没有带来一致收益。后续将围绕联合模型的泛化表现、生境信息相对临床资料的增量价值及特征稳定性继续研究。这批患者与划分已用于前期开发，本阶段结果属于内部探索。

## 结果核查

在仓库根目录执行：

```powershell
python tools/verify_public_results.py
```

该工具核对五折均值和标准差、混淆矩阵指标、汇总表一致性与源码哈希，无需患者数据。患者级AUC、bootstrap区间的重算及模型重训需要相应的私有输入。

## 训练与数据

当前阶段的训练入口是 `original_source/lvi_prediction/run_dualroute_directpls_20261025.py`。完整训练链使用原工程的影像、ROI、结局、临床变量、病例映射、历史特征缓存和冻结记录，相关前置条件见源码阅读说明。

仓库提供研究源码与群体汇总结果；医院影像、临床表、病例对应关系、逐例特征和预测保存在受控环境。取得数据使用授权后，可在相同数据布局与依赖环境中继续实验。

## 方法与开发来源

生境表征参考Chen等MRI生境研究，特征提取采用PyRadiomics，聚类、PLS与分类采用scikit-learn，图像处理使用SimpleITK和NiBabel，详见 `REFERENCES.md`。开发过程中使用ChatGPT与Codex进行方案讨论、代码生成与调试、结果核查及文字整理；实验数值来自实际程序输出。

本仓库按持续研究项目维护，课程技术报告和组会材料可作为不同阶段的研究成果。每次新增实验应分别记录问题、队列、方案、结果与解释，保留能够复核的版本。
